Faraday Starter

Faraday Starter makes flashing a USB stick and rebooting into Faraday easy. Download it and open it: it puts Faraday on your stick, then guides you step by step through restarting your computer into it.

For Linux and Windows, x86-64. macOS coming soon.

Linux33 MB Windows38 MB macOScoming soon
  1. Open Faraday StarterOn the computer you use every day. Nothing to install first.
  2. Make your Faraday stickPlug in a USB stick, or a microSD card for a Raspberry Pi, and choose it. Faraday Starter writes Faraday to it and checks what it wrote.
  3. Start from the stickIts guide shows the steps for your computer, one at a time, and how to set the computer back afterwards.
Opening it the first time

LinuxThe file comes in a .tar.gz. Extract it with a double-click, then open the file inside. Writing a stick may ask for your password. It runs on Ubuntu 20.04 and later, Debian 11 and later, Fedora 32 and later, and Arch.

WindowsWindows shows "Windows protected your PC" the first time, because the file is not code-signed: a certificate would name a verified person, and Faraday is published under a pseudonym. Check the file against SHA256SUMS, as in Verify below, then choose More info, Run anyway.

An antivirus warningAn antivirus can flag a new program that is not code-signed. Faraday Starter changes only what you ask it to: the stick it writes, an install if you choose one, a restart when you say. Check the file against SHA256SUMS before running it.

What you need

A laptop or a Raspberry Pi, and soon a Mac. Prices are rough, in US dollars.

A laptop

The better machine: its screen, keyboard and webcam are inside the case.

  • An x86-64 laptop with UEFI firmware: the one you have, or, for the most caution, a dedicated one with its Wi-Fi card and internal disk taken out$0, or $100 to $200
  • A webcam to scan QR codes: the built-in one, or a USB webcam$0 to $20
  • A USB stick of 256 MB or larger for Faraday's imageabout $8
  • A second USB stick for files, optionalabout $8

A MacComing soon

In the works. What it will support, from Apple's and Asahi Linux's documentation:

  • Intel Macs with 64-bit EFI, which leaves out the 2006 and some 2007 models, start the laptop's stick image. Macs with the T2 chip (2018 to 2020) take a USB keyboard, and their Startup Security is lowered while Faraday is used.Intel
  • M1 and M2 Macs start a stick image of their own, through a start-up file Faraday Starter sets up once and the Mac's recovery system seals. macOS keeps Full Security, and Faraday Starter can remove the file again.M1, M2
  • M3 once Asahi Linux's support for it is released; M4 and M5 once Asahi's boot code starts on them.Later

SourcesApple's pages that identify each Mac model, and Asahi Linux's feature-support pages. Faraday's README will list each model.

Any USB stick or microSD card of 256 MB or larger will do. Faraday's own boot file is about 14 MB on a stick and 16 MB on a Pi card; the rest of its 64 MiB boot partition is room for later versions to grow, and a 128 MiB partition beside it holds your files.

A desktop PC works too, with a plain monitor. Not a smart TV, a capture card or a KVM switch: each can record what Faraday shows, and a network KVM can also type on it.

Download and start

With Faraday Starter, or by hand.

  1. Download

    The image for your machine, SHA256SUMS and SHA256SUMS.asc, from the files below or the release on GitHub.

    Release 0.1.6

  2. Verify

    The release key was made in Faraday and its secret part has never left a Faraday vault. Its fingerprint:

    D1AF A712 ABEF 9010 9A1B 587F F153 6BE0 7E23 4CFD

    gpg --import release-key.asc
gpg --fingerprint F1536BE07E234CFD
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS

    On Windows, Gpg4win's gpg takes the first three commands, and PowerShell prints a file's sum to compare with its line in SHA256SUMS:

    Get-FileHash -Algorithm SHA256 .\faraday-stick-0.1.6-x86_64-uefi.img.xz
    release-key.asc

  3. Write the stick

    Faraday Starter writes the stick or card and reads it back. By hand, use a tool that writes whole disk images, such as Raspberry Pi Imager (Use custom) or balenaEtcher, which take the .img.xz as it is, or dd on Linux. Writing erases the stick: check its name with lsblk first.

    xz -dc faraday-stick-0.1.6-x86_64-uefi.img.xz | sudo dd of=/dev/sdX bs=4M conv=fsync status=progress

  4. Start from the stick

    Follow the steps in Faraday Starter, on the computer Faraday will run on. It shows them for that computer's maker, in order, and the steps that put the computer back afterwards.

    On Windows, Secure Boot back on first.Turn Secure Boot back on before Windows starts again. Windows started with Secure Boot off asks for the drive's 48-digit recovery key.

    By hand: turn Secure Boot off in the firmware settings, choose the stick in the boot menu, and turn Secure Boot back on afterwards. On a Pi, put the card in and power it on.
